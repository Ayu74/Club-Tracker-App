BUILD THE APK (no Android Studio, no coding, ~10 minutes, free)

1. Create a free account at github.com and make a NEW repository (private is fine).
2. Click "uploading an existing file" and drag in EVERYTHING from this folder,
   including the hidden ".github" folder (upload by dragging the whole unzipped
   folder contents). Click "Commit changes".
3. Open the "Actions" tab. The "Build APK" job starts by itself (about 5-8 min).
   If it does not, click "Build APK" > "Run workflow".
4. When it shows a green tick, open it and download "Club-Tracker-APK" at the bottom.
   Unzip it -> app-debug.apk.
5. Send the APK to your phone, tap it, and allow "Install unknown apps" when asked.

In the app: "Download" opens the Android share sheet - choose Drive, Files,
WhatsApp, Gmail, etc. to save the updated Excel.
